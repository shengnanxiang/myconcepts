# MyConcepts

我的概念原型库。用来存放日常探索的产品概念与交互 Demo，作为各种原型的统一入口。

## 项目定位

把零散的产品想法变成可点击、可体验的真实原型，而非停留在文档。每个概念一个 Demo，
统一在首页 `index.html` 入口陈列，点开即进入对应原型。

## 概念原型：冲扫 3 小时的意义（AiKen 相机）

### Summary

AiKen 是一台「模拟胶卷体验」的数码相机概念。核心创意是把胶卷的仪式感带进数码摄影：
每次最多拍 36 张（环形进度计数）、可先选一种胶片风格、随时「取出冲扫」
（删除相机内照片、恢复 36 张、把已拍照片以「一卷」为单位送入 Dark Room 冲扫）。
本项目用纯前端（HTML/CSS/JS，无框架、无后端）还原了它的完整交互流程，
并保留了参考站点「左展示 + 右留言」的双向互动形态。

### 设计来源

- 交互框架参考站点 `demo.hanntonb.com/demo/923fdfc82e07/`（左侧 Demo + 右侧评论模块）。
- 具体界面来自 Figma 设计稿导出的 7 张状态图（`figma/01.png` ~ `figma/07.png`），
  对应：初始 / 已拍 29 张 / 风格列表 / 已选风格 / 拍满 36 张 / 卷轴照片 / Dark Room。

### 交互流程（7 个状态）

| 步骤 | 状态 | 表现 |
|------|------|------|
| 01 | 初始 | 36 张全空，未选风格，底部「提前取出」不可点 |
| 02 | 已拍 29 | 剩余 7 张，未选风格，底部仍不可点 |
| 03 | 风格列表 | 顶部标签筛选 + 风格卡片，点 SELECT 选择风格 |
| 04 | 已选风格 | 剩余 7 张，已选 Cinestill 800T，底部「提前取出」可点 |
| 05 | 拍满 36 | 命令变为「取出并冲扫」 |
| 06 | 卷轴照片 | 一卷内全部照片，已套用风格，「Save All」导出 |
| 07 | Dark Room | 已完成/正在冲扫的胶卷列表，点进即看该卷 |

### 原型特性

- **可点击交互**：顶部步骤按钮切换状态；风格列表 SELECT 后自动回到 Camera 并带上已选风格；
  Dark Room 点某卷 → 跳到该卷照片 + 右侧输出区同步预览。
- **真机手机框**：橙色边框 + 深色屏幕 + 环形进度 + 胶片色调，1:1 还原 Figma 比例风格。
- **真实样片**：`photos/` 下 5 卷共 110 张真实照片接入卷轴详情、Dark Room 缩略图与输出区胶片预览。
- **右侧留言区**：基于 `localStorage`，刷新不丢，无需后端，支持昵称（可选）与相对时间。
- **响应式**：窗口 < 980px 时上下堆叠。

### 如何预览

照片用相对路径引用（含中文目录名，已做 `encodeURIComponent`），需通过本地服务器访问，
直接双击 `file://` 打开可能加载不出图片：

```bash
cd myconcepts
python -m http.server 8123
# 打开 http://localhost:8123/index.html
```

## 概念原型：与口袋照片打印机的联动（AiKen × Ricotta）

### Summary

把「数字影像重新拿回手里」的蓝牙联动三步演示：在手机上配对口袋打印机，
拍下的瞬间即可通过蓝牙无线印放成实物。Demo 由「手机（米家 App）｜AiKen 相机｜
连接图标｜Ricotta 打印机」四段构成，每一步都带设备状态（开关机 / 电量 / 蓝牙灯）
与引导提示，完整模拟配对、拍照、印放的真实体验。

### 三步流程

| 步骤 | 名称 | 表现 |
|------|------|------|
| 01 | 配对绑定 | 手机侧发起配对，短按打印机电源键确认，弹出「配对成功」遮罩 |
| 02 | 拍照 | 相机快门拍照，计数剩余张数，照片回显到取景区 |
| 03 | 印放 | 照片经蓝牙传输到打印机，完成无线印放成实物 |

### 原型特性

- **可点击交互**：顶部步骤指示器可跳转 / 返回；配对成功前「拍照」「印放」均锁定。
- **设备状态可视化**：两设备均展示开关机、电量、蓝牙指示灯，操作会联动更新。
- **真实样图**：`photo_mini.jpg` 用作拍照与印放的预览样图。
- **响应式**：窗口 < 900px 时四段垂直堆叠，连接图标自动旋转适配。

### 如何预览

直接访问首页卡片或该页面：

```bash
cd myconcepts
python -m http.server 8123
# 打开 http://localhost:8123/shoot-print/shoot-print.html
```
